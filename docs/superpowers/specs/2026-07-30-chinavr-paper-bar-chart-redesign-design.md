# ChinaVR 论文统计图统一柱状图修订设计

## 1. 目标与范围

本次修订响应终版审阅意见，将论文中的五张统计结果图恢复为柱状图，并统一粗细、间距、配色、字号和留白。实验数据、图号、图题、正文结论、参考文献和图7马赛克均保持不变。

改造范围：

- 图3：独立短句集各情感类别 F1。
- 图4：多模态消融结果。
- 图5：感知与口型模块中位时延。
- 图6：TTFA 各阶段中位数与 P95。
- 图8：用户研究六项平均评分。

图2混淆矩阵与图7系统界面不属于柱图改造范围，保持现状。

## 2. 已确认布局

### 2.1 图3：横向分组柱

- 每个情感类别占一行。
- 字符模型与规则分支使用两根并列横柱。
- 横轴范围为 0--1。
- 数值标注放在柱端；接近右边界时改放柱内，避免裁切。

### 2.2 图4：横向分组柱

- 每个模态或融合配置占一行。
- 准确率与 Macro-F1 使用两根并列横柱。
- 横轴范围为 0--105%，给 100% 数值标签保留余量。
- 方法顺序与正文和表3一致，不按数值重新排序。

### 2.3 图5：竖向单柱

- 五个模块分别使用一根等宽竖柱。
- 保留对数纵轴，以表达 0.01 ms 到 1.8 ms 的数量级差异。
- 所有柱使用主蓝色，数值标注置于柱顶。
- 横轴标签保留轻微旋转，防止中文标签重叠。

### 2.4 图6：竖向并列柱

- 四个阶段沿横轴排列。
- 每个阶段使用两根等宽并列柱，分别表示中位数与 P95。
- 中位数使用蓝色，P95 使用橙色。
- 纵轴从 0 开始，柱顶标注整数毫秒值。
- 图例置于绘图区上方，避免遮挡柱体。

### 2.5 图8：竖向并列柱

- 六项主观评分沿横轴排列。
- 每个指标使用两根并列柱，分别表示基线与本文方法。
- 纵轴保持 1--5 分范围，并在柱顶显示两位小数。
- 基线使用橙色，本文方法使用蓝色。

## 3. 统一视觉规范

五张统计图共用以下规范：

- 基准柱宽为 `0.32`；单系列图使用 `0.52`，视觉重量与分组柱保持一致。
- 蓝色 `#2f6f9f` 表示主要模型、本文方法、中位数或第一指标。
- 橙色 `#d58a3c` 表示规则分支、基线、P95 或第二指标。
- 柱体使用白色细边框，边框宽度 `0.45`，避免相邻柱粘连。
- 组间留白一致，图内不绘制横向或纵向背景网格。
- 仅保留左、下坐标轴，顶部与右侧边框隐藏。
- 图例优先放置在绘图区上方并采用两列布局。
- 数值标签字号、偏移量和小数精度按数据类型统一。
- 保存尺寸与论文当前版心匹配，避免在 LaTeX 中缩放后文字过小。

## 4. 实现与数据流

继续使用 `paper/experiments/run_paper_experiments.py` 作为唯一统计图生成入口：

1. 从现有 `experiment_results.json` 和补充实验数据读取结果。
2. 五个绘图函数只改变视觉编码，不修改数值、排序或统计过程。
3. 同时生成 PDF 与 PNG。
4. 将生成结果同步到终版 Overleaf 目录。
5. 重新编译 `main.tex`，覆盖终版 PDF 和 Overleaf ZIP。

- 自动检查五张图均包含预期数量的柱形对象。

- 检查原始数值与柱高或柱长一一对应。
- 生成五图总览并进行视觉检查，重点检查标签裁切、图例遮挡和柱间距。
- 重新编译论文，确认无未定义引用、缺图或 `Overfull`。
- 将最终 PDF 全部页面栅格化并逐页检查。
- 检查 Overleaf ZIP 完整且不含编译中间文件。
